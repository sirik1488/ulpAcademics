Создать своё расписание

Вставьте ваше расписание в текстовом виде, и нейросеть поможет отформатировать его для импорта.

Инструкция:
1. Вставьте ваше расписание в поле ниже.
2. Нажмите «Получить промт» — скачается файл prompt.md.
3. Отправьте этот файл нейросети (ChatGPT, Claude и др.).
4. Нейросеть вернёт JSON-конфиг. Важно: скопируйте только JSON-код и сохраните в файл с расширением .json.
5. Нажмите «Восстановить из файла» в меню настроек и выберите сохранённый JSON.

Пример формата расписания для вставки:
Понедельник: 8:00-14:30
1. История (15)
2. Англ (2)
... и так далее для каждого дня.
